# dsh-claude-theme

DSH 的配色、字体和正文排版，照 Claude 桌面版调。只改样式变量和少量排版规则，不动任何组件。

## 内容

- **配色**：替换 DSH 的两条色阶（`neutral-bluish` 中性灰、`deepseek` 强调色）和常用别名。
  - 浅色：底色 `#fcfcfb`、侧栏 `#fbfbf9`、选中 `#f0efec`、正文 `#141413`。
  - 深色：底色 `#262624`、侧栏 `#1f1e1d`、卡片 `#30302e`。
  - 强调色是 Claude 的陶土橙 `#d97757`，链接 `#1b65b1`，行内代码暗红字 `#8a2424`。
- **字体**：界面用 Anthropic Sans，代码用 Anthropic Mono，`--cui-font-serif` 提供 Anthropic Serif。DSH 里写死的 `Inter` 也指向 Anthropic Sans。中文回退到系统字体（与 Claude 一致）。
- **正文排版**
  - 标题 600 字重、只比正文略大，上方留白减半；段距 10px。
  - 行内代码改成普通行内文本（不再是带框的胶囊块）。
  - 表格：单元格留白收紧、取消 100px 最小列宽，宽度跟随正文栏，放不下就在格内换行。
  - 4 列以上的「宽表格」不再向两侧出血（原生实现在列表里会算错偏移、悬停时滚动条切换导致页面跳动）。
- **滚动条**：细而淡。

## 字体

字体文件不在仓库里（版权归 Anthropic，不能再分发）。不放字体也能用，会回退到系统字体。放法见 [`fonts/README.md`](fonts/README.md)。

字体由插件的宿主半边通过 `GET /api/claude-fonts?f=sans|serif|mono` 提供给浏览器端，只认这三个白名单名字，不接受任意路径。

## 自定义

所有颜色都在 `client.js` 顶部的 CSS 里，按「静态色阶 / 浅色 / 深色」三段组织，改值即可。正文字号仍然跟随 DSH「设置 → 字号大小」。
